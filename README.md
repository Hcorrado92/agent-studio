# Agent Studio

Plataforma web para crear agentes de IA mediante conversaciones en lenguaje natural.

Este repositorio lo desarrolla de forma autónoma **AI Software Factory** (Autopilot), un ítem del backlog por rama `factory/agent-studio/NN-...`, con PRs en draft para revisión humana. La especificación está en [`docs/SPEC.md`](docs/SPEC.md).

- `backend/`: FastAPI + SQLAlchemy (dependencias en `backend/requirements.txt`).
- `frontend/`: React + TypeScript + Vite + Tailwind.

Las instrucciones para ejecutar la aplicación se completan durante el desarrollo.
